# Nine-quark colour code: allowed-error algebra and syndrome-extraction cost

19 October 2026. Follow-up to PR #43, COLOUR_SIGN_TWIST_THEOREM_AND_RECOVERY.md.
**Status:** theorem-level finite-dimensional algebra and new numerical regression. Not an engineering design of local fault-tolerant colour syndrome measurements.

## 1. Which colour exchanges are physically gauge-invariant?

The nine colour qutrits represent nine *distinguishable* SU(3)-fundamental tensor factors. Their 42D global singlet representation is a physical Gauss sector only if they transform under **one common gauge transformation** (e.g. as matter at a common lattice vertex, with appropriate spin/flavour/spatial antisymmetry).

For two fundamentals with exchange S, S(T^a⊗I+I⊗T^a)=(T^a⊗I+I⊗T^a)S, but [S,T^a⊗I]≠0. The program computes both commutators in the exact two-qutrit (9D) Hilbert space for all eight Gell-Mann generators.

Hence a bare colour exchange is SU(3) gauge invariant for **co-located** fundamentals sharing a gauge vertex. For independently gauged spatial sites it fails the independent Gauss constraints. Physical distant exchange requires gauge-field parallel transport/link dressing and changes the operator and error model; this study **does not** simulate those links.

The nine-quark code being a *global colour singlet* does not by itself prove that its protected Hilbert space is a viable nine-site gauge-invariant memory.

## 2. Connected exchange interactions destroy passive protection

Inside the nine-quark colour singlet, permutations act in the irreducible Specht module of S9 with partition (3,3,3), dimension 42. Transpositions along **any connected graph** generate the entire permutation group S9. By Burnside's theorem, the complex associative operator algebra generated by that irreducible representation is the **entire M₄₂(C)** (dimension 1,764).

Therefore no nontrivial decoherence-free subspace/subsystem is protected **solely by SU(3) gauge symmetry** against the complete associative algebra of possible connected exchange words. This is a theorem about the *allowed algebra*, not evidence that arbitrary long exchange words occur at high rate or that every Hermitian matrix can be efficiently reached by calibrated exchange pulses. A graph of disconnected exchange couplers generates only permutations within components, and needs a separate representation restriction analysis.

The sign-twist code K (dimension 21) has K†S_ij K=0 for all 36 transpositions. So a **single exchange event is detectable**, and a known-pair noise channel {I,S_ij} has the exact recovery established by PR #43. But for unknown locations, the error family {I,S_12,S_23} is already **not jointly correctable**: the composite overlap K†S_12 S_23 K is **not scalar**. The source code reports its Frobenius deviation.

For a two-edge Hamiltonian H=(S_12+S_23)/2, K†HK=0 yet K†H²K is nonscalar, producing logical distortion at **second order in time**. Thus zero first-order compression is not exact passive suppression.

This is consistent with the general interaction/error-algebra distinction of Knill, Laflamme and Viola (2000), Phys. Rev. Lett. 84, 2525, DOI https://doi.org/10.1103/PhysRevLett.84.2525.

## 3. Full arbitrary one-quark colour errors need 65 coherent syndrome labels

Use normalized colour generators T^a=λ^a/2, a=1,…,8, and the 73 labeled error basis elements E_0=I and E_(i,a)=T_i^a for quark i=1,…,9.

On the +i sign-twist code K, global colour singlet invariance implies:

  K† T_i^a K = 0,
  K† T_i^a T_j^b K = δ_ab c_ij I₂₁,

where

  c_ii = 1/6,      c_ij = −1/48 (i≠j).

Derivation: On one site the SU(3) quadratic Casimir Σ_a(T_i^a)²=4/3, giving 8 c_ii=4/3. For distinct sites, Σ_a T_i^a T_j^a=(S_ij−I/3)/2 and K†S_ijK=0, giving 8 c_ij=−1/6. The adjoint indices can only couple through δ_ab by singlet covariance.

The 9×9 site Gram for each of eight a values has a **zero uniform mode** (the Gauss/global-colour relation Σ_i T_i^a K=0) and eight eigenvalues 3/16. With one additional identity direction, the 73×73 Knill–Laflamme Gram matrix has

  eigenvalue 1 (multiplicity 1),
  eigenvalue 3/16 (multiplicity 64),
  eigenvalue 0 (multiplicity 8).

Its **rank is exactly 65**.

The new program constructs eight orthogonal *relative-site* Helmert contrasts f_μ, with Σ_i f_μi=0, and defines syndrome-error isometries proportional to Σ_i f_μi T_i^a K; 8 independent contrasts times 8 SU(3) adjoint labels plus the identity provide **65 mutually orthogonal 21D error images**. This is an abstract constructive recovery/syndrome decomposition, not a compiled gate sequence.

A projective extraction that explicitly resolves every such orthogonal syndrome requires **at least 65 orthogonal pointer labels**. Therefore it needs *at least four qutrit ancilla registers* (3³=27<65≤81=3⁴), or seven qubit registers (2⁶=64<65≤128=2⁷). The combined correctable image occupies 21×65=1,365 states inside the full 3⁹=19,683-dimensional colour register.

**Important:** this is an *orthogonal-label dimension bound for the full correctable error span*, not a universal lower bound on fault-tolerant circuit depth, interacting ancillas, gates, locality, or other recovery schemes. In a gauge-invariant implementation the syndrome environment's adjoint labels must transform covariantly; direct measurement of a fixed colour-axis component could violate the physical gauge constraints. The comparison with the earlier five-plaquette SU(3) two-qutrit pointer information bound is not a like-for-like physical measurement-cost comparison.

## 4. What the code does and does not establish

| Question | Status |
|---|---|
| All 36 individual exchanges detected? | Yes, exact sign-twist identity (PR #43) |
| A known-pair exchange channel correctable? | Yes, explicit abstract CPTP recovery (PR #43) |
| Unknown arbitrary exchange locations correctable? | **No**, two distinct swap Kraus operators already violate KL |
| All connected gauge-invariant exchange words passively harmless? | **No**, full M42 complex associative algebra |
| All arbitrary single-quark colour errors correctable? | Yes, exact KL theorem; abstract 65-label orthogonal decomposition |
| Four qutrits enough to label 65 syndromes? | Yes **informationally**, not a synthesized gauge-covariant circuit |
| Bare exchange gauge-invariant across separated vertices? | **No**; link dressing is needed |
| Real physical confinement-derived memory demonstrated? | **No** |

Next milestone: construct an explicitly local, gauge-covariant extraction circuit on a minimal gauge-link simulator or establish a useful locality/control-depth lower bound. Run noisy syndrome extraction with *physically implementable* operations and compare a matched unencoded storage protocol. Another productive direction is **restricting the allowed exchange graph/errors** (e.g. mediated/limited bridges), not claiming blanket protection from SU(3) symmetry.
